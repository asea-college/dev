# ASEA 교직원 AI 공동 개발 및 교육

학교 공용 개발 실습 저장소입니다. 기존 운영 웹앱과 분리하여 관리합니다.

## 폴더
- common/: 디자인 기준과 AI 작업 지침
- training/week-01/: 강사용 진행안, 학습자용 안내서, 실습 프롬프트, 과제
- projects/staff-01 ~ staff-10/: 교직원별 실습 공간

## 이용 규칙
1. 개인 GitHub 계정으로 공동 작업자 초대를 수락합니다.
2. 각자 배정된 projects/staff-XX 폴더에서 작업합니다.
3. 자신의 브랜치에서 작업한 뒤 Pull Request로 변경을 제안합니다.
4. 다른 사람의 파일과 공통 파일은 승인 없이 수정하지 않습니다.
5. 실제 학생·교직원 개인정보, 비밀번호, 토큰, API 키를 올리지 않습니다.
6. 운영 중인 학사정보시스템과 기존 ASEA 웹앱은 실습 대상으로 사용하지 않습니다.

주의: 일반 공동 작업자 권한만으로 폴더별 쓰기 권한이 분리되지는 않습니다. 저장소 공개 여부와 브랜치 보호 규칙은 관리자가 확인합니다.
