# 교직원 AI 바이브 코딩 1차 교육 및 실습 안내

이번 교육에서는 ChatGPT와 Claude 등 AI 도구를 이용하여 간단한 업무용 웹 프로그램을 직접 만들어 봅니다. 코딩 경험이 없어도 자연어로 필요한 기능을 설명하고, 결과를 확인하면서 수정하는 방식으로 참여할 수 있습니다.

교육에서는 GitHub 공동 개발 저장소의 이용 방법을 먼저 살펴본 뒤, 메모 관리 웹앱을 제작하고 검색 기능을 추가하는 실습을 진행합니다. Codex와 Claude Code를 사용할 수 있는 교직원은 해당 도구로도 참여할 수 있으며, 무료 채팅 도구만으로도 실습할 수 있도록 안내합니다.

교육자료는 학교 GitHub 저장소의 training/week-01 폴더에 준비했습니다.
https://github.com/asea-college/dev/tree/main/training/week-01

개발 시에는 common 폴더의 디자인 기준을 참고하고, 본인에게 배정된 projects/staff-XX 폴더에서 작업해 주시기 바랍니다. 공동 작업자 초대와 폴더 배정은 별도로 안내합니다.

실습 중 궁금한 점이나 오류가 발생하면 이 포럼에 사용 도구, 작업 내용, 오류 메시지와 시도한 방법을 올려주시기 바랍니다. 다음 교육에서는 공유된 사례를 함께 살펴보겠습니다. 화면 캡처를 올릴 때는 학생정보와 비밀번호 등을 반드시 가려주시기 바랍니다.

이번 주 과제로는 담당 업무에서 반복되는 작업 한 가지를 선정하고, AI로 개선할 수 있는 프로그램 아이디어를 작성해 보시기 바랍니다.

다음 시간에는 AI를 이용한 브라우저 업무 자동화 개념을 소개할 예정입니다. 실제 학사정보시스템이 아닌 테스트 화면을 통해 조회와 입력을 돕는 방법을 살펴보겠습니다.
