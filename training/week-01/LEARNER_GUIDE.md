# 교직원 AI 바이브 코딩 1차 교육 학습자료

교육일: 2026년 11월 13일(금)
교육시간: 약 60분
실습환경: Windows PC, 인터넷, 개인 GitHub 계정

## 1. 오늘 배우는 내용
이번 시간에는 AI에게 자연어로 업무용 프로그램 제작을 요청하고, 만들어진 결과를 직접 확인하고 수정하는 과정을 실습합니다. 코딩 경험이 없어도 참여할 수 있습니다.

오늘의 목표는 다음 세 가지입니다.
1. AI 개발 도구와 GitHub의 역할 이해
2. 메모 관리 웹앱 제작 및 기능 수정
3. 공동 저장소에서 자신의 실습 결과 관리

## 2. 사용할 도구
- ChatGPT: 자연어로 요구사항 정리, 코드 생성 및 수정. 무료 채팅 사용량 제한이 있습니다.
- Claude: 동일한 목적으로 사용 가능합니다. 무료 채팅 사용량 제한이 있습니다.
- Codex: 저장소 및 프로젝트를 다루는 AI 개발 도구입니다. 계정별 접근 가능 여부와 사용량을 확인해야 합니다.
- Claude Code: 프로젝트 파일을 직접 다루는 개발 도구입니다. 일반적인 무료 Claude 채팅과는 이용 조건이 다르며 유료 구독 또는 API 비용이 필요할 수 있습니다.
- GitHub: 소스 파일 보관, 변경 내역 확인, 공동 작업에 사용합니다. 기본 기능은 무료로 시작할 수 있습니다.

유료 개발 도구를 사용할 수 없는 참여자는 ChatGPT 또는 Claude 채팅에서 코드를 생성하여 GitHub 웹 화면으로 파일을 등록하는 방식으로 실습합니다.

## 3. 학교 개발 환경
학교 공용 저장소: https://github.com/asea-college/dev

저장소의 common 폴더에는 공통 디자인 기준이 있고, training 폴더에는 교육자료가 있습니다. projects 폴더는 개인별 실습 공간입니다.

개인 GitHub 계정으로 초대를 수락하고 자신에게 배정된 폴더를 확인합니다. 저장소 공동 작업자라고 해도 다른 사람의 파일을 수정하지 않습니다. 가능하면 개인 브랜치에서 작업하고 변경 내용을 Pull Request로 제출합니다.

## 4. 실습 순서
1. ChatGPT 또는 Claude에 접속합니다.
2. 아래 실습 프롬프트를 복사하여 입력합니다.
3. 생성된 HTML 파일을 확인하고 브라우저에서 실행합니다.
4. 메모 등록, 수정, 삭제 및 새로고침 후 데이터 유지를 확인합니다.
5. AI에게 검색 기능 추가를 요청합니다.
6. 결과를 본인의 실습 폴더에 반영합니다. 직접 커밋할 때는 다른 파일을 변경하지 않았는지 확인합니다.

### 첫 번째 프롬프트
교직원이 사용할 간단한 업무용 메모 웹앱을 HTML, CSS, JavaScript로 만들어 주세요. 메모 등록, 수정, 삭제가 가능하고 새로고침 후에도 내용이 유지되어야 합니다. 데이터는 브라우저 localStorage에 저장하고 서버나 로그인을 사용하지 마세요. PC와 모바일에서 사용하기 편하게 구성해 주세요. 학교의 common/DESIGN_SYSTEM.md와 common/css/tokens.css에 적힌 디자인 기준을 참고해 주세요. 다만 파일을 직접 읽을 수 없다면 먼저 관련 내용을 요청해 주세요. 결과는 index.html 한 파일로도 실행할 수 있게 작성하고 실행 방법을 알려 주세요.

### 두 번째 프롬프트
기존 기능을 유지하면서 메모 검색 기능을 추가해 주세요. 수정한 부분과 확인할 테스트 항목을 설명해 주세요.

## 5. 결과 확인
메모를 두 건 등록하고, 한 건을 수정하고, 한 건을 삭제해 봅니다. 새로고침 후 남은 메모가 유지되는지 확인합니다. 검색어를 입력했을 때 해당 메모만 표시되는지도 확인합니다.

주의: localStorage는 현재 브라우저에 저장되는 방식이므로 다른 PC나 휴대폰으로 자동 동기화되지 않습니다. 실제 학생정보나 민감한 업무자료를 입력하지 않습니다.

## 6. 질문과 과제 제출
학교 AI 포럼에 사용한 도구, 만들려던 기능, 어려웠던 부분, 시도한 해결 방법을 작성합니다. 오류 화면을 첨부할 때는 개인정보와 인증정보를 가립니다.

과제: 자신의 업무에서 반복되는 작업 한 가지를 선정하여 AI로 개선할 수 있는 프로그램 아이디어를 작성하고, 가능하면 간단한 시제품을 만들어 봅니다.
