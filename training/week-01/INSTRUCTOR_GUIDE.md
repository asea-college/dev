# 교직원 AI 바이브 코딩 1차 교육 강사용 진행안

대상: 교직원 약 10명, 코딩 경험 없는 참여자 다수
일시: 2026년 11월 13일(금), 약 60분
방식: 강사 시연 후 각자 실습, AI 포럼 질문 공유

## 시간별 진행
- 0~5분: 지난주 발족식 및 토론 내용 연결, 오늘의 결과물 안내
- 5~15분: AI 채팅과 코딩 도구 차이, GitHub의 역할 설명
- 15~25분: 학교 dev 저장소 구조, 개인 브랜치와 실습 폴더, 공통 디자인 기준 안내
- 25~40분: 자연어로 메모 웹앱 만들기. 무료 ChatGPT/Claude를 기본 경로로 시연
- 40~50분: 검색 기능 추가, 오류 해결, 결과 확인
- 50~57분: 개인 폴더 반영 또는 Pull Request 시연, AI 포럼에 질문 등록
- 57~60분: 과제 안내와 다음 시간 브라우저 자동화 예고

## 강의 핵심 설명
AI가 코드를 생성하더라도 요구사항과 결과 검증은 사람이 맡습니다. ChatGPT와 Claude의 무료 채팅은 텍스트 생성 경로이며, Codex와 Claude Code의 저장소 직접 수정 기능은 별도 접근 권한과 사용 조건이 필요할 수 있습니다. GitHub는 AI 모델이 아니라 파일 저장과 협업을 위한 공간입니다.

## 강사 시연
1. https://github.com/asea-college/dev 열기
2. common/DESIGN_SYSTEM.md 및 AGENTS.md 소개
3. training/week-01/LEARNER_GUIDE.md의 프롬프트를 복사
4. ChatGPT 또는 Claude에서 코드 생성
5. index.html을 테스트하고 검색 기능 추가
6. 개인 브랜치와 Pull Request의 의미 시연
7. 포럼 질문 예시: '메모를 수정한 뒤 새로고침하면 내용이 사라집니다. localStorage 저장 부분을 어떻게 확인할까요?'

## 강사 체크리스트
- 참석자 개인 GitHub 로그인 가능 여부
- 저장소 공동 작업자 초대 수락 여부
- 각자 배정 폴더 확인 여부
- 무료 도구로 실습할 대체 경로 제공 여부
- 개인정보 및 인증정보 사용 금지 안내
- 메모 등록·수정·삭제·검색·새로고침 테스트 여부
- 포럼 질문 또는 과제 등록 여부

## 수업 후 피드백
참여자별로 사용한 AI 도구, 제작 결과, 해결한 오류, 다음에 만들 업무 프로그램을 간단히 기록합니다. 결과물의 완성도보다 요구사항을 설명하고 오류를 개선하는 과정을 우선 평가합니다.
