# ASEA 교육용 웹앱 디자인 기준 v0.1

기존 일정관리 웹앱에서 참고한 디자인 요소를 토대로 정리한 **교육용 초안**입니다. 학교 전체의 확정 디자인 표준은 아닙니다.

## 색상
- 주 강조색: #1A73E8
- 진한 강조색: #1557B0
- 연한 강조색: #E8F0FE
- 화면 배경: #F0F9FF
- 카드: #FFFFFF
- 본문: #202124
- 보조 문구: #5F6368
- 테두리: #E8EAED
- 성공: #34A853
- 주의: #FBBC05
- 오류: #EA4335

## 타이포그래피와 레이아웃
- 글꼴: Noto Sans KR, 시스템 sans-serif
- 기본 글자 크기: 14px
- 기본 모서리: 6px
- 헤더 높이: 56px
- PC와 모바일 모두 지원하는 반응형 화면
- 명확한 버튼 이름, 입력 안내, 오류 표시, 키보드 접근성 적용

## 사용 방법
새 웹앱의 CSS에서 common/css/tokens.css에 정의된 변수를 참고합니다. 하위 폴더의 웹페이지에서는 상대 경로를 정확히 계산해야 합니다. 이 파일을 AI에 제공하고 임의의 색상·간격을 무분별하게 추가하지 않도록 지시합니다.
